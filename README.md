# bundangzip-v2

12월 리모델링을 앞두고, 가족이 집의 현재 모습을 살펴보며 바꾸고 싶은 점을 함께 기록하는 공간입니다.

[사이트 바로가기](https://bundangzip-v2.vercel.app)

실측 평면도를 바탕으로 집의 구조와 가구 배치를 2D·3D로 살펴봅니다. 현재 모습과 리모델링 후 모습을 전환할 수 있으며, 리모델링 후 공간은 기존 구조 위에 새로운 가구 배치를 채워갈 예정입니다.

방, 주방, 거실, 발코니 등 원하는 공간을 선택해 의견을 남깁니다. 특정 공간에 속하지 않는 생각은 집 전체 의견으로 기록합니다. 누가 어디에 어떤 생각을 남겼는지 평면도와 의견 목록에서 함께 볼 수 있습니다.

- 의견은 최신순으로 모이고, 공간별 필터와 작성일별 접기·펼치기를 지원합니다.
- 의견 카드에서 공간을 누르면 평면도에서 해당 위치가 강조됩니다.
- 채택·기각 피드백으로 의견을 정리하고, 필요하면 검토 중으로 되돌릴 수 있습니다. 이전 피드백은 남아 결정 과정을 돌아볼 수 있습니다.

공용 비밀번호를 입력하고 구성원을 선택하면 시작할 수 있습니다. 선택한 구성원은 기기에 기억되며, 이용 중에도 바꿀 수 있습니다. 모든 과정은 한 페이지에서 이어집니다.
